# Read Me When…

An online Quran verse jar. Pick how you feel, or reach into the jar and pull out a slip. Each slip unrolls to show a verse in Arabic with an English translation, plus a short reflection question.

## Features
- 8 feelings: anxious, sad, lonely, angry, guilty, lost, grateful, happy (about 125 verses)
- A physical jar: tap or drag slips out, swipe to stir, shake the jar
- Background nasheed while a slip is open
- Save favourite slips (stored in your browser only)

## Live site
https://saadmohammed-cloud.github.io/read-me-when/

## Run it
Open `index.html` in a browser. There's no build step.
